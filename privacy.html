Політика конфіденційності

Чинна редакція: 24 червня 2026 р.

1. Хто ми

Bogatyrev Marketing Team — команда performance-маркетингу з України, сертифікований Google Partner. Ведемо рекламні кабінети клієнтів у Google Ads та Meta Ads з 2019 року.

2. Які дані ми збираємо

2.1. Контактні дані, які ви добровільно надаєте при зверненні: ім'я, email, Telegram-нік, опис запиту.

2.2. Знеособлена аналітика відвідувань наших публічних сторінок (кількість переглядів, тип пристрою).

2.3. Дані рекламних кабінетів клієнтів, до яких ми отримали доступ за договором або через MCC-зв'язок — виключно для виконання послуг з налаштування та оптимізації реклами.

2.4. Дані з Google Ads API, коли клієнт надає доступ до свого акаунту через OAuth: метрики кампаній, ключових слів, оголошень, конверсій. Використовуємо лише для автоматизації внутрішньої звітності та моніторингу за MCC.

3. Як ми використовуємо дані

  • Контактні дані — для відповіді на ваш запит і комунікації по проєкту.
  • Дані рекламних кабінетів — виключно для управління рекламою клієнта: планування кампаній, оптимізація, звітність.
  • Внутрішні інструменти автоматизації, побудовані на базі Google Ads API, обробляють метрики кампаній виключно в межах нашої команди — для внутрішньої звітності та сповіщень. Доступ до цих інструментів мають тільки штатні співробітники.

4. Як ми захищаємо дані

  • Усі облікові дані (API-токени, OAuth refresh tokens, ключі доступу) зберігаються в зашифрованих файлах оточення. Вони не публікуються у відкритих репозиторіях.
  • Доступ до даних клієнтських акаунтів обмежений штатними співробітниками за принципом мінімальних привілеїв.
  • Усі канали зв'язку захищені (HTTPS, end-to-end месенджери).
  • Резервні копії зберігаються в зашифрованому вигляді на приватній інфраструктурі.

5. Передача даних третім сторонам

Ми не передаємо і не продаємо ваші контактні дані та дані клієнтських рекламних кабінетів третім сторонам. Виключення — випадки, коли передача обумовлена:

  • прямою вказівкою клієнта (наприклад, підключення GA4 до Google Ads);
  • вимогою законодавства України.

6. Використання Google API

Наші інструменти автоматизації використовують Google Ads API виключно для внутрішніх потреб команди (звітність, моніторинг, оптимізація кампаній клієнтів під керуванням нашого MCC). Використання Google API даних відповідає Google API Services User Data Policy, включно з вимогами Limited Use.

Ми не використовуємо дані з Google API для тренування AI-моделей, не передаємо їх третім сторонам і не використовуємо для реклами, не пов'язаної з клієнтським акаунтом.

7. Термін зберігання

Контактні дані зберігаються протягом строку співпраці плюс 12 місяців. Дані рекламних кабінетів обробляються протягом дії договору з клієнтом; історичні метрики можуть зберігатися до 24 місяців для аналізу трендів.

8. Ваші права

Ви можете в будь-який час:

  • запросити копію ваших даних, які ми зберігаємо;
  • виправити або видалити свої дані;
  • відкликати OAuth-доступ до Google Ads через свій акаунт Google;
  • подати скаргу до Уповноваженого Верховної Ради України з прав людини.

9. Зміни політики

Ми залишаємо за собою право оновлювати цю Політику. Актуальна версія завжди доступна за цією адресою. Про суттєві зміни повідомимо email-ом клієнтам з активними договорами.
